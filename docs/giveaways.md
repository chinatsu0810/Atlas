# 「譲る」仕様

帰国・引越しの不用品を、海外に住む日本人同士で譲り合う掲示板。スモールスタートで、利用状況を見ながら広げる。

## 方針

- 運営は場の提供のみ。決済は持たず、代金のやり取りと受け渡しは当事者同士で行う。
- 価格は「無料」または「金額＋通貨」。表示するだけ。通貨は一覧から選ぶか、「その他」で自由記載（空欄なら「現地通貨」）。
- 受け渡し可能期限は今日から1年以内。編集で期限を消すと今日から30日、再掲載では期限を消して今日から30日。
- 一覧・詳細はログインなしで閲覧できる。投稿・コメントはログインが必要。
- 手数料を取る、決済を組み込む、業者の出品を認める、利用規模が大きくなる、のいずれかの段階で、法的な扱いを専門家に確認する。

## 状態

| 状態 | 値 | 遷移 |
|---|---|---|
| 募集中 | `open` | 投稿時。予定のキャンセル・辞退で戻る。期限切れから再掲載で戻る |
| 予定者決定 | `reserved` | 投稿者が希望者を「受け渡し予定者に決定」 |
| 受け渡し済み | `handed_over` | 投稿者が「受け渡した」 |
| 完了 | `completed` | 予定者が「受け取りを確認」、または受け渡し済みから7日（日次ジョブ） |
| 取り下げ | `withdrawn` | 投稿者が取り下げ（募集中・予定者決定から） |
| 期限切れ | `expired` | 募集の期限を過ぎた（日次ジョブ）。期限は、受け渡し可能期限があればその日の終わり（UTC）、なければ投稿から30日 |

## やりとり

- 希望者のコメントは、投稿者と希望者の1対1スレッド（`giveaway_threads`）になる。ほかの人には見えない（件数だけ表示）。
- 予定者に決まると、そのスレッドがそのまま取引ページになる。ほかのスレッドは締め切り（閲覧のみ）。
- 状態の変化は、スレッドに system メッセージとして残す。
- 取引ページは10秒ごとに自動更新する（リアルタイム通信は使わない）。開いたら既読になる。

## 通知

- メール（Resend）。本文にメッセージの内容は載せず、投稿タイトルとリンクだけ。
- 新着メッセージのメールは、同じスレッド・同じ相手に15分に1通まで。
- サイト内: ヘッダーのマイページに赤い点、マイページの「譲る」に未読件数。

| きっかけ | 送る相手 |
|---|---|
| 新しいコメント（スレッドの作成） | 投稿者 |
| 新着メッセージ | 相手（15分に1通まで） |
| 予定者に決定 | 予定者 ／ ほかの希望者（募集終了） |
| 予定のキャンセル・辞退 | 相手 ／ ほかの希望者（募集再開） |
| 受け渡した | 予定者 |
| 受け取りを確認 | 投稿者 |
| 取り下げ | 希望者全員 |
| 通報 | 運営（contact@atlas-community.jp） |

## 禁止品

- リストと判定は [lib/giveaways/prohibited-items.ts](../lib/giveaways/prohibited-items.ts)。語の追加・削除はこのファイルだけ編集すればよい。
- タイトル・説明に禁止語があると、画面でポップアップを出して投稿させない。サーバーでも同じ判定をする。
- 表記ゆれ（全角半角、大文字小文字、空白）は吸収する。カタカナ語は、前後がカタカナなら一致させない（「ワイン」は「ワイングラス」に一致しない）。
- 普通の投稿まで止めてしまう語（「現金」「クレジットカード」など、支払い方法の説明で使われる語）は入れていない。

## 写真

- ブラウザで長辺1600pxに縮小し、JPEGに描き直してから、Vercel Blob に直接アップロードする（位置情報などのExifはここで消える）。
- アップロード用のトークンは [app/api/giveaways/upload/route.ts](../app/api/giveaways/upload/route.ts) がログイン中のユーザーにだけ発行する。
- 編集で外した写真と、退会ユーザーのパージ時の写真は、Blob からも削除する。投稿を途中でやめた場合の写真は残る（件数が増えたら掃除のジョブを検討する）。

## 使い方ページのイラスト

- [public/images/giveaways/guide/](../public/images/giveaways/guide/) のSVG 8枚（`giver-1〜4`、`taker-1〜4`）。
- Canvaで編集できるよう、文字なし・グラデーションなし・色は要素に直接指定している。
- Canvaで編集したら、同じファイル名で上書きする。PNGで書き出した場合は、[app/giveaways/guide/page.tsx](../app/giveaways/guide/page.tsx) の `image` のパスを変える。

## 保持期間

- コメント・メッセージ: 完了・取り下げ・期限切れから1年でスレッドごと削除（[lib/retention/giveaways.ts](../lib/retention/giveaways.ts)。日次ジョブ）。
- 退会時の扱いは [account-deletion.md](account-deletion.md) を参照。

## 公開の手順

1. Vercel で Blob ストアを作り、プロジェクトに接続する（環境変数 `BLOB_READ_WRITE_TOKEN` が入る）。ローカルで試すなら `.env` にも入れる。
2. マイグレーション `0021_giveaways.sql` を本番DBに適用する。`npm run db:migrate` は使えない（[account-deletion.md](account-deletion.md) の「注意」）。SQLを直接実行する。
3. デプロイ後、投稿 → 別アカウントでコメント → 予定者に決定 → 受け渡した → 受け取りを確認、を一通り試し、各段階でメールが届くことを確認する。
