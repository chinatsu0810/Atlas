# 集まる（イベント）

海外で、日本語で参加できるイベントを見つけるための機能。利用者は投稿できず、運営が登録する。

- 主催者から依頼を受けたもの（お問い合わせ経由）と、運営が選んだものを載せる
- 公開ページ: `/gather`（一覧）、`/gather/[id]`（詳細）
- 運営画面: `/account/gather-events`（追加・編集・公開／下書き・削除）。マイページの「運営」から入る
- 開発中のあいだは `app/gather/layout.tsx` で「ただいま準備中です」のお知らせを出している。正式に公開するときは外す

## データ

テーブルは `gather_events`（[schema.ts](../lib/db/schema.ts)）。

- `published_at` が NULL なら下書き。公開ページには出さない（運営は詳細ページで確認できる）
- 削除は `deleted_at` を入れるだけで、行は残す
- 一覧に出すのは、日本時間の前日以降に開催されるもの
- 詳細ページの「確認日」は `updated_at`
- 詳細ページの「参加する前に読んでおきたい経験談・Q&A」は、同じ国の投稿から、経験談・Q&Aそれぞれ2件。イベントと同じテーマのタグがついたものを先に出し、足りなければ同じ国の新着で補う

## 本番への反映

マイグレーション `0024_gather_events.sql` は**本番DBに適用済み**（2026-09-28。SQLを1トランザクションで直接実行。22列・インデックス2つを確認済みで、行は0件）。`npm run db:migrate` は使えない（[account-deletion.md](account-deletion.md) の「注意」）。SQLを直接実行する。

テーブルがない間も、公開ページは「まだ掲載中のイベントはありません」と表示し、運営画面はテーブルがない旨を表示する。
